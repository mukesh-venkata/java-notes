# ⚡ Blocks — Quick Revision

> **Topic 13 • 30-Second Revision**

## 🧠 Master Idea

~~~text
CLASS
  ↓
Static initialization

OBJECT
  ↓
Instance initialization
  ↓
Constructor
~~~

## 📊 Remember This Table

| Concept | Easy Meaning |
|---|---|
| Block | Statements inside { } |
| Static block | Class-level initialization |
| Instance block | Initialization during object construction |
| Constructor | Initializes a newly created object |

## 🔥 Three-Line Memory Trick

**Static → Class**

**Instance → Object**

**Constructor → Initialize Object**

## 🎯 Object Creation Flow

~~~text
new Student()
      ↓
Instance fields / instance block
      ↓
Constructor
~~~

</details>

<details>
<summary>Instance block?</summary>
<br>

Runs during object construction before the constructor body.

</details>

<details>
<summary>Constructor?</summary>
<br>

Runs as part of object creation and initializes the object.

</details>

<details>
<summary>Static block every object?</summary>
<br>

No.

</details>

<details>
<summary>Instance block every object construction?</summary>
<br>

Yes.

</details>
