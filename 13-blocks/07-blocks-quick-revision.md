## 🧠 Master Idea

~~~text
CLASS
  ↓
Static initialization

OBJECT
  ↓
Instance initialization
  ↓
Constructor
~~~

## 📊 Remember This Table

| Concept | Easy Meaning |
|---|---|
| Block | Statements inside { } |
| Static block | Class-level initialization |
| Instance block | Initialization during object construction |
| Constructor | Initializes a newly created object |

## 🔥 Three-Line Memory Trick

**Static → Class**

**Instance → Object**

**Constructor → Initialize Object**

## 🎯 Object Creation Flow

~~~text
new Student()
      ↓
Instance fields / instance block
      ↓
Constructor
~~~

## 🎤 Interview One-Liners

**Static block?** Runs during class initialization.

**Instance block?** Runs during object construction before the constructor body.

**Constructor?** Runs as part of object creation and initializes the object.

**Static block every object?** No.

**Instance block every object construction?** Yes.
