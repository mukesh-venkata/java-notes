# 📚 1. Java Standard Library — Overview

> **Core idea:** The Java Standard Library (Java API) provides predefined, reusable code for common programming tasks.

## 🧠 What Is the Java Standard Library?

Java comes with a large collection of predefined:

- Packages
- Classes
- Interfaces
- Methods

These APIs help developers perform common tasks without implementing everything from scratch.

Think of it as:

~~~text
Java Standard Library / API
          ↓
       Packages
          ↓
        Types
          ↓
       Methods
~~~

## 🎯 Why Use It?

The standard library provides ready-to-use functionality for areas such as:

- Collections
- Input / Output
- Date and time
- Networking
- Text processing
- Utility operations

This improves reuse and reduces unnecessary code.

## 🔍 Package → Class → Method

For example:

~~~text
java.lang
    ↓
  String
    ↓
 length()
~~~

Here:

- `java.lang` → package
- `String` → class
- `length()` → method

## 📌 Common Standard Packages

| Package | Common purpose |
|---|---|
| `java.lang` | Core language classes |
| `java.util` | Collections and utilities |
| `java.io` | Input / Output |
| `java.time` | Date and time |
| `java.net` | Networking |

## 🧠 Important Terminology

**API** = Application Programming Interface.

In Java, the Java API is the documented collection of packages and types provided for developers to use.

> **Remember:** A package organizes related types; a class or interface provides a particular type; methods provide operations.
