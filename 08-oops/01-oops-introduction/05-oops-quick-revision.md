## 🧠 Master Mnemonic

### **A-E-I-P**

| Letter | Pillar | Remember |
|---|---|---|
| **A** | Abstraction | Hide unnecessary details |
| **E** | Encapsulation | Bundle + control access |
| **I** | Inheritance | Derive from another class |
| **P** | Polymorphism | Different behavior through a common type |

---

## 🏗️ Class vs Object

```text
Class  → defines a type
Object → instance of that type
Reference → refers to an object
```

Example:

```java
Student s = new Student();
```

```text
Student       → type
s             → reference
new Student() → creates object
```

## 🎤 Interview One-Liners

**OOP?** → Programming around objects, state and behavior.

**Four pillars?** → Abstraction, Encapsulation, Inheritance, Polymorphism.

**Class?** → A type definition.

**Object?** → An instance of a class.

**Reference?** → A variable that refers to an object.

**hashCode unique?** → No, uniqueness is not guaranteed.
