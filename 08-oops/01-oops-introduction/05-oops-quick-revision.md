## 🧠 Master Mnemonic

### **A-E-I-P**

| Letter | Pillar | Remember |
|---|---|---|
| **A** | Abstraction | Hide unnecessary details |
| **E** | Encapsulation | Bundle + control access |
| **I** | Inheritance | Derive from another class |
| **P** | Polymorphism | Different behavior through a common type |

---

## 🏗️ Class vs Object

```text
Class  → defines a type
Object → instance of that type
Reference → refers to an object
```

Example:

```java
Student s = new Student();
```

```text
Student       → type
s             → reference
new Student() → creates object
```
