# 02. Java Editions

Java is available in different editions for different application needs.

## Java Editions

| Edition | Full Name | Purpose |
|---|---|---|
| **Java SE** | Standard Edition | Core Java and standard APIs |
| **Java EE** | Enterprise Edition | Enterprise-level applications; now known as **Jakarta EE** |
| **Java ME** | Micro Edition | Mobile and embedded devices |

### Quick Understanding

- **Java SE** → Core Java
- **Java EE / Jakarta EE** → Enterprise applications
- **Java ME** → Mobile & embedded devices

### 30-Second Revision

**SE = Standard → EE = Enterprise → ME = Micro**

### Interview Question

**Q: What are the main Java editions?**

**A:** Java SE for core Java, Java EE (now Jakarta EE) for enterprise applications, and Java ME for mobile/embedded environments.
