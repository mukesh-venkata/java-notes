# 06. Features of Java

Java provides a combination of portability, object-oriented programming, automatic memory management and runtime optimization.

## Key Features

### 1. Platform Independent

Java source code is compiled into bytecode, which can run on different platforms through their JVM.

### 2. WORA

**Write Once, Run Anywhere**

Bytecode can be executed on different platforms using compatible JVM implementations.

### 3. Portable

Java bytecode can be moved across different platforms and executed using a compatible JVM.

### 4. Architecturally Neutral

Java bytecode is not dependent on a specific processor architecture.

### 5. Multithreading

Java supports multiple threads executing concurrently.

### 6. Automatic Garbage Collection

The JVM automatically identifies and reclaims memory occupied by unreachable objects.

### 7. OOPs

Java supports the major object-oriented programming concepts:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

### 8. Just-In-Time (JIT) Compiler

The JIT compiler can compile frequently executed bytecode into native machine code at runtime to improve execution performance.
