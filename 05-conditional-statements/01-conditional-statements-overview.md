# 🔀 Java Conditional Statements — Overview

> **Topic 12 • Java Fundamentals**

Conditional statements control which block of code executes based on a condition.

---

## 🎯 Why Use Conditional Statements?

Programs often need to make decisions:

```text
Is age >= 18?
      │
   ┌──┴──┐
  Yes    No
   │      │
 Adult   Minor
```

A condition normally produces a `boolean` result:

```java
age >= 18
```

---

## 🧩 Main Types

### 🧠 Memory Trick: **N-I-E-I-S**

| Letter | Statement |
|---|---|
| **N** | Nested `if` |
| **I** | `if` |
| **E** | `if-else` |
| **I** | `if-else-if` |
| **S** | `switch` |

These can be grouped as:

```text
Conditional Statements
        │
        ├── if
        │    ├── if-else
        │    ├── if-else-if
        │    └── nested if
        │
        └── switch
```

---

## 📌 Quick Comparison

| Statement | Typical use |
|---|---|
| `if` | Execute code only when a condition is true |
| `if-else` | Choose between two paths |
| `if-else-if` | Choose among multiple conditions |
| Nested `if` | Make a decision inside another decision |
| `switch` | Select among multiple discrete cases |

## 🎤 Interview Quick Check

**Q1. What are conditional statements?**  
A: Statements used to control program flow based on conditions.

**Q2. What type of value does a Java condition normally produce?**  
A: `boolean`.

**Q3. What are the main Java decision-making constructs?**  
A: `if`, `if-else`, `if-else-if`, nested `if`, and `switch`.
